# Working in this repository

This repository contains the public CERTCRYPT specifications. Keep every
contribution self-contained and suitable for public distribution.

- Write for readers who have this repository and the public sources it links to.
- Describe current requirements and behavior. Avoid change-history narratives
  in normative text.
- Include only information needed to understand, implement, or evaluate the
  public specifications.
- Do not add secrets, personal data, environment-specific values, or
  unpublished material.
- Write commit messages in English.
- Run the repository checks before committing. Do not bypass them; report a
  false positive instead.
