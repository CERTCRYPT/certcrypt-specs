## What is `operator.recognition/1`?

`operator.recognition/1` defines the credential a node presents to show that its operator key is recognised under the CERTCRYPT System Domain, the operator identifier derived from that key, and the checks — signature, validity window and proof of possession — the fixation service performs before admitting what the node submits.

It does **not** define:

- a registry or list of operators
- how the fixation service decides to recognise an operator
- any input to the verification of an independence proof
- any rating, ranking, endorsement or certification of operators
